УстановкаInstall

Сборки самодостаточные: .NET ставить не нужно.Builds are self-contained: .NET is not required.

Windows 10/11 x64

Распакуйте DemReview-<версия>-win-x64.zip и запустите DemReview.exe. Если SmartScreen предупредит — «Подробнее → Выполнить в любом случае».Unpack DemReview-<version>-win-x64.zip and run DemReview.exe. If SmartScreen warns — More info → Run anyway.

Linux x64

Распакуйте и запустите:Unpack and run:
tar -xzf DemReview-*-linux-x64.tar.gz
./DemReview-*-linux-x64/DemReview

Первый запускFirst start

Программа спросит язык интерфейса — его можно сменить потом в «Настройках».The app asks for the interface language — you can change it later in Settings.

ПошаговоStep by step

Разбор демкиReviewing a demo

Шаг 1–2Steps 1–2

Откройте демку и выберите игрокаOpen a demo and pick a player

  • «Файл → Открыть демку» (Ctrl+O), перетаскивание .dem на окно или «Открыть с помощью → DemReview».File → Open demo (Ctrl+O), drag a .dem onto the window, or Open with → DemReview.
  • Разбор идёт в фоне, отмена — Esc. Повторное открытие той же демки — из кеша за секунды.Parsing runs in the background; Esc cancels. Reopening the same demo takes seconds thanks to the cache.
  • Выберите игрока в списке слева — все вкладки покажут только его. Ниже — фильтры: раунд, сторона, закупка, тип гранаты.Pick a player in the list on the left — every tab now shows only them. Below are filters: round, side, buy, grenade type.

Шаг 3Step 3

Радар и повтор раундаRadar and round replay

  • Слои включаются справа: маршруты, гранаты, смерти, тепловая карта. Зум — колесом, сдвиг — перетаскиванием, сброс — двойным кликом.Layers are toggled on the right: routes, grenades, deaths, heatmap. Zoom with the wheel, pan by dragging, double-click to reset.
  • Выберите раунд в списке «Раунды» — появится таймлайн: «Пуск» или ползунок, скорость ×0,5–×8.Select a round in the Rounds list to open the timeline: press Play or drag the slider, speed ×0.5–×8.
  • Наведите мышь на игрока — ник, оружие и HP. Списки «Частые», «Гранаты» и «Тайминги» подсвечивают свои раунды и раскидки.Hover a player to see the nickname, weapon and HP. The Frequent, Grenades and Timings lists highlight their rounds and lineups.

Шаг 4Step 4

СтатистикаStatistics

  • «Ситуации игрока» — каждый раунд: сторона, закупка, счёт и что игрок сделал.Player situations — every round: side, buy, score and what the player did.
  • «Условия → действия» — частотные таблицы: как часто решение следует за условием.Conditions → actions — frequency tables: how often a decision follows a condition.
  • «Раунды матча» — закупки обеих команд по раундам.Match rounds — both teams' buys per round.

Шаг 5–6Steps 5–6

Профиль игрока и экспортPlayer profile and export

  • Паттерн показывается, если встречается не реже 60% случаев и минимум в 3 раундах; оба порога меняются на вкладке.A pattern is shown if it happens in at least 60% of cases and in at least 3 rounds; both thresholds can be changed on the tab.
  • Смотрите на «N из M» и цвет точки: зелёный — высокая уверенность, жёлтый — средняя, серый — низкая. Одна демка — малая выборка.Look at "N of M" and the dot color: green — high confidence, yellow — medium, grey — low. One demo is a small sample.
  • «Показать на радаре» накладывает раунды-примеры паттерна.Show on radar overlays the pattern's example rounds.
  • Экспорт — Ctrl+E: Markdown или JSON по расширению файла, текст на языке интерфейса.Export — Ctrl+E: Markdown or JSON by file extension, text in the interface language.

Вкладка «Настройки»: язык, кеш разобранных демок, папки данных и карт, проверка обновлений и статистика использования.The Settings tab: language, parsed demo cache, data and map folders, update check and usage statistics.

Частые вопросыFAQ

Где взять демку?Where do I get a demo?
  • Ваши матчи в CS2: «Смотреть → Ваши матчи» → скачать запись. Файл .dem появится в папке игры game\csgo\replays.Your CS2 matches: Watch → Your Matches → download the replay. The .dem file appears in the game folder game\csgo\replays.
  • FACEIT: на странице матча — кнопка скачивания демки.FACEIT: the match page has a demo download button.
  • Профессиональные матчи: демки GOTV публикуются на HLTV.Pro matches: GOTV demos are published on HLTV.

Если демка пришла в архиве (.zip, .rar, .gz, .zst), сначала распакуйте её.If the demo comes in an archive (.zip, .rar, .gz, .zst), unpack it first.

Подходят ли демки CS:GO?Do CS:GO demos work?

Нет, только Counter-Strike 2: формат демок CS:GO другой.No, only Counter-Strike 2: CS:GO demos use a different format.

Windows пишет «Система Windows защитила ваш компьютер»Windows says "Windows protected your PC"

Это SmartScreen: программа не подписана платным сертификатом. Нажмите «Подробнее → Выполнить в любом случае». Код открыт, а подлинность архива можно проверить по SHA256SUMS.txt из релиза.That's SmartScreen: the app is not signed with a paid certificate. Click More info → Run anyway. The code is open, and you can verify the archive with SHA256SUMS.txt from the release.

Что нужно для запуска на Linux?What do I need on Linux?

Linux x64 и графический сеанс с X11 или XWayland. Всё остальное, включая .NET, уже внутри сборки.Linux x64 and a desktop session with X11 or XWayland. Everything else, .NET included, ships inside the build.

Почему паттернов мало или уверенность низкая?Why are there few patterns, or low confidence?

Одна демка — это 20–30 раундов, из них на каждой стороне вдвое меньше. Программа учитывает малую выборку и не выдаёт случайные совпадения за привычки.One demo is 20–30 rounds, and half that per side. The app accounts for the small sample and doesn't present coincidences as habits.

Пороги (60% и 3 раунда) можно снизить на вкладке «Профиль игрока», но тогда чаще будут попадаться случайности.You can lower the thresholds (60% and 3 rounds) on the Player profile tab, but you'll see more coincidences.

Как добавить свою карту?How do I add my own map?

Без изображения радар рисуется на сетке — всё остальное работает. Чтобы добавить подложку:Without an image the radar is drawn on a grid — everything else works. To add a background:

  • возьмите из файлов игры game/csgo/panorama/images/overheadmaps/<карта>_radar_psd.png;take game/csgo/panorama/images/overheadmaps/<map>_radar_psd.png from the game files;
  • переименуйте в <карта>.png и положите в папку maps рядом с программой («Настройки → Папки»).rename it to <map>.png and put it in the maps folder next to the app (Settings → Folders).

Для точного совмещения нужны координаты карты в коде — подробности в maps/README.txt. Или попросите добавить карту.Exact alignment needs the map's coordinates in the code — see maps/README.txt. Or ask for the map to be added.

Как обновить программу?How do I update the app?

Когда выходит новая версия, в программе появляется баннер со ссылкой. Скачайте новую сборку и распакуйте её на место старой — настройки и кеш хранятся отдельно и сохранятся.When a new version is out, the app shows a banner with a link. Download the new build and unpack it over the old one — settings and cache are stored separately and are kept.

Что программа отправляет в сеть и как это отключить?What does the app send over the network, and how do I turn it off?

Демки, файлы, ники и SteamID не отправляются никогда. Есть два необязательных запроса, оба отключаются в «Настройках»:Demos, files, nicknames and SteamIDs are never sent. There are two optional requests, both can be turned off in Settings:

  • проверка обновлений — один запрос к GitHub при запуске;update check — one request to GitHub on start;
  • анонимная статистика (Aptabase) — запуск программы и загрузка демки: карта, из кеша или разбор, время разбора, плюс версия, ОС и язык системы. Постоянного идентификатора пользователя нет.anonymous statistics (Aptabase) — app start and demo load: map, cache or parse, parse time, plus version, OS and system language. There is no persistent user ID.
Нашёл ошибку или есть идеяI found a bug or have an idea

Напишите в Issues на GitHub. Для ошибки приложите журнал из папки logs (открывается в «Настройках → Папки») и, если можно, ссылку на демку.Open an issue on GitHub. For a bug, attach the log from the logs folder (open it from Settings → Folders) and, if possible, a link to the demo.
