# DemReview

[English](README.md) · **Русский** · [Сайт](https://pank0rekt.github.io/demreview-cs2/)

DemReview — десктопное приложение для анализа поведения **конкретного игрока** по демке Counter-Strike 2 (`.dem`):
как он перемещается по карте, какие гранаты кидает, как реагирует на ситуацию в раунде и какие привычки
повторяются настолько часто, что становятся предсказуемыми. Одна демка — малая выборка, поэтому DemReview умеет
строить сводный профиль игрока по многим демкам и вести ваш личный профиль, который растёт с каждым матчем.
Работает офлайн на Windows и Linux.

![Радар: все маршруты, гранаты и смерти одного игрока](docs/images/radar-routes.png)

> **О проекте.** DemReview — пет-проект, сделанный с помощью [Claude Code](https://claude.com/claude-code).

## Что показывает

- **Игроки.** Обе команды отдельными списками: У / С / П, разница убийств и смертей, поиск по нику; вы отмечены «Вы».
- **Радар.** Все маршруты игрока на подложке карты, гранаты от броска до детонации (зоны дыма и огня), смерти,
  тепловые карты позиций или смертей. Зум колесом или кнопками «+» и «−», сдвиг перетаскиванием.
- **Повтор раунда.** Таймлайн с воспроизведением (×0,5–×8): все игроки с направлением взгляда, ник при наведении
  мышью, киллфид как в игре (убийства и смерть игрока выделены), всплывающий урон над жертвами
  (нанесённый — жёлтый, полученный — красный), урон гранат у места взрыва и контекст момента: живые, деньги,
  закупки, бомба, счёт.
- **Фильтры.** Раунд, сторона, закупка команды (пистолетка, эко, форс, фулл-бай), тип гранаты.
- **Статистика.** Плитки-сводка (раунды, победы, урон за раунд, первый контакт — всего и по сторонам) и каждый раунд
  как «условия → решение»: сторона, закупка и счёт против маршрута, итоговой позиции, гранат, агрессии, первой дуэли,
  урона. Частотные таблицы показывают, как часто решение следует за условием.
- **Профиль игрока.** Индекс предсказуемости, роль на каждой стороне с ключевыми метриками и обоснованием, сравнение
  T и CT, устойчивые паттерны («На T при закупке «фулл-бай» в 7 из 9 раундов идёт TSpawn → SideAlley → TopofMid»)
  с фильтром по категориям и уверенностью с учётом малой выборки одной демки. Клик — раунды-примеры паттерна на радаре.
- **Гранаты.** Какие гранаты принесли пользу: урон HE и огня по противникам (в том числе на гранату), скольких
  противников и своих ослепила каждая флешка и на сколько, убийства ослеплённых, пока они не видели, урон своим.
  Таблица сравнивает всех игроков матча, а у каждого броска игрока виден результат. Одна кнопка открывает бросок
  на таймлайне радара за пару секунд до него, на паузе, — чтобы посмотреть, как летит граната.
- **Библиотека раскидок.** Сохраняйте понравившиеся броски: позиция, угол и как бросали (в прыжке, присев, шагом).
  Одна кнопка копирует `setpos` / `setang`: встаньте в точку на своём сервере и отработайте бросок.
- **Библиотека и профиль по многим демкам.** Добавьте папку с демками — DemReview разберёт каждую один раз и сохранит
  анализ. Выберите игрока (он находится в каждой демке по SteamID), карту и демки — паттерны, роли, радар и тепловые
  карты посчитаются по всем раундам вместе. Профиль строится из библиотеки за секунды, даже если файлов `.dem` уже нет.
- **Мой профиль.** Каждая открытая демка с вашим участием сама сохраняется в библиотеку — ваш профиль растёт с каждым
  матчем.
- **Экспорт** профиля в Markdown или JSON.
- **Настройки** прямо в программе, включая пороги анализа.

## Скачать

Последняя сборка — на странице [Releases](../../releases/latest). Сборки самодостаточные: .NET ставить не нужно.

- **Windows 10/11 x64:** распакуйте `DemReview-<версия>-win-x64.zip` и запустите `DemReview.exe`.
  Программа не подписана, поэтому SmartScreen может предупредить при первом запуске:
  «Подробнее → Выполнить в любом случае».
- **Linux x64:** распакуйте и запустите:
  ```bash
  tar -xzf DemReview-<версия>-linux-x64.tar.gz
  ./DemReview-<версия>-linux-x64/DemReview
  ```
  Нужен графический сеанс с X11 или XWayland.

К каждому релизу приложен `SHA256SUMS.txt` для проверки файлов.

## Как пользоваться

Слева в окне — полоса разделов («Радар», «Статистика», «Профиль», «Гранаты», «Библиотека», «Настройки», внизу — кнопка открытия демки),
рядом — матч и его игроки, справа — выбранный раздел.

1. **Откройте демку:** кнопка «Открыть демку» (Ctrl+O), перетащите `.dem` на окно или передайте путь в командной
   строке (на Windows — «Открыть с помощью → DemReview»). Разбор идёт в фоне, прогресс — внизу окна, отмена — Esc.
2. **Выберите игрока** в панели игроков: команды идут отдельными списками, ник ищется в строке поиска. Все разделы
   показывают этого игрока. При первой демке DemReview предложит выбрать себя как *основного игрока*: дальше вы будете
   выбраны сразу при открытии демки и отмечены «Вы» в списке (SteamID можно ввести и в «Настройках»).
3. **Радар.** Фильтры (сторона, раунд, закупка, гранаты) — над картой, слои включаются справа. Выберите раунд
   в списке «Раунды» (или в фильтре раунда) — появится таймлайн: кнопка воспроизведения или ползунок, скорость ×0,5–×8.
   Наведите мышь на игрока — ник, оружие, HP. Вкладки «Частые», «Гранаты» и «Тайминги» подсвечивают свои раунды
   и раскидки на радаре.
4. **Статистика.** Плитки сверху — сводка по раундам, победам, урону и первому контакту; сторона и закупка
   переключаются прямо на странице. «Ситуации игрока» — все раунды; «Условия → действия» — частотные таблицы;
   «Раунды матча» — закупки обеих команд.
5. **Профиль игрока.** Паттерн показывается, если встречается не реже 60% случаев и минимум в 3 раундах; оба порога
   меняются на странице или в «Настройках». Смотрите на «N из M» и цвет точки уверенности (зелёный — высокая,
   жёлтый — средняя, серый — низкая): одна демка — малая выборка. Чипы категорий сужают список; клик по паттерну
   подсвечивает раунды-примеры, «На радаре» — ещё и переключает на радар.
6. **Экспорт** профиля — Ctrl+E или кнопка «Экспорт профиля»: формат по типу файла (`.md` или `.json`), текст —
   на языке интерфейса.
7. **Гранаты.** Плитки — урон HE и огнём, ослеплённые противники, убийства ослеплённых и ослеплённые свои; ниже —
   таблица всех игроков матча. В «Бросках игрока» у каждого броска видно, куда он прилетел и что сделал. Кнопки
   у броска (здесь и во вкладке «Гранаты» на радаре):
   - ▶ открывает раунд на таймлайне радара за 2 с до броска, на паузе: нажмите воспроизведение и смотрите полёт;
   - копирование кладёт в буфер `setpos x y z;setang pitch yaw 0`: вставьте в консоль своего сервера
     с `sv_cheats 1` — окажетесь в точке броска с тем же прицелом;
   - закладка сохраняет бросок в «Библиотеку раскидок» справа. Раскидки фильтруются по карте и типу гранаты,
     название можно изменить.

   Как двигался игрок при броске, записывается начиная с v0.3.0; у демок, разобранных раньше, — после повторного
   разбора (Shift+F5).
8. **Библиотека.** «Добавить папку с демками» разбирает в библиотеку все `.dem` из папки (включая подпапки);
   «Обновить» добавляет новые и изменённые демки из всех папок. Выберите игрока («Мой профиль» выбирает вас) и карту —
   в списке его демки на ней со счётом с его стороны и У / С / П. Отметьте демки и нажмите «Построить профиль»: все
   разделы (радар, статистика, профиль) покажут сводный матч, раунды в нём пронумерованы подряд, а карточка «Демки
   в профиле» показывает, какие раунды из какой демки. Профиль строится по одной карте: привычки на разных картах
   разные. Отдельную демку тоже можно открыть из списка — из файла или, если его уже нет, из сохранённого анализа.
9. **Настройки:** язык интерфейса, основной игрок (ваш SteamID), кеш разобранных демок (заполненность, очистка),
   папки данных и карт, пороги анализа, проверка обновлений, статистика использования.

### Данные и настройки

Каталог данных: Windows — `%LOCALAPPDATA%\DemReview`, Linux — `~/.local/share/DemReview`.

- `settings.json` — настройки, пороги анализа, размер и положение окна;
- `demreview.db` — кеш разобранных демок (SQLite, последние 50; можно удалить или очистить в «Настройках»);
- `library.db` — библиотека демок для сводных профилей (SQLite, без лимита, не очищается вместе с кешем; очистка —
  на странице «Библиотека»). Сами файлы `.dem` не изменяются и не удаляются;
- `lineups.json` — библиотека раскидок (хранится отдельно от кеша и библиотеки демок);
- `logs/` — журналы за 14 дней.

Пороги анализа правятся в «Настройках → Пороги анализа» (применяются после «Анализировать заново», F5; шаг выборки —
после разбора без кеша, Shift+F5) или прямо в `settings.json`:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `Language` | — | `ru` или `en`; нет значения — спросить при запуске |
| `CheckForUpdates` | `true` | Проверять новый релиз на GitHub при запуске |
| `SendUsageStatistics` | `true` | Отправлять анонимную статистику (запуск, загрузка демки) |
| `MainPlayerSteamId` | — | Ваш SteamID64: выбирается автоматически и отмечается «Вы» в списке игроков |
| `MainPlayerPromptDisabled` | `false` | Не предлагать выбрать себя при открытии демки |
| `DemoFolders` | `[]` | Папки с демками библиотеки: «Обновить» разбирает из них новые демки |
| `SaveMyDemosToLibrary` | `true` | Сохранять в библиотеку каждую открытую демку, где играет основной игрок |
| `SampleTickStep` | 16 | Шаг выборки позиций, тиков (8–16) |
| `GrenadeClusterThrowDistance` | 150 | Порог точек броска в одной раскидке, units |
| `GrenadeClusterLandDistance` | 250 | Порог точек детонации в одной раскидке, units |
| `BuyEcoMaxEquipment` | 1500 | Средняя экипировка ниже — эко, $ |
| `BuyFullMinEquipment` | 3700 | Средняя экипировка не ниже — фулл-бай, $ (между — форс) |
| `AggressiveContactSeconds` | 20 | Первый бой не позже — агрессивный раунд, с |
| `PassiveContactSeconds` | 50 | Первый бой не раньше (или его нет) — пассивный раунд, с |
| `PatternMinShare` | 0.6 | Минимальная частота паттерна |
| `PatternMinExamples` | 3 | Минимум раундов-примеров паттерна |

### Обновления и приватность

DemReview не отправляет ваши демки, файлы и данные игроков. Сетевых запросов два, оба необязательные; без сети
программа работает как обычно:

- **Проверка обновлений** — запрос последнего релиза на GitHub при запуске («Настройки → Обновления и приватность»).
  Если вышла новая версия, баннер ведёт на страницу релиза; обновление ставится вручную — скачиванием новой сборки.
- **Анонимная статистика использования** через [Aptabase](https://aptabase.com) — помогает понять, сколько людей
  пользуется программой. Отправляются только два события: запуск программы и загрузка демки (карта, из кеша или
  разбор, время разбора), а также версия программы, ОС и язык системы. Имена файлов, ники, SteamID и постоянный
  идентификатор пользователя не отправляются. Отключается переключателем в «Настройках → Обновления и приватность».
  Статистику отправляют только релизные сборки; в сборках из исходников ключа нет и она выключена.

## Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download).

```bash
git clone https://github.com/Pank0REKT/demreview-cs2.git
cd demreview-cs2
dotnet build DemReview.slnx
dotnet test --solution DemReview.slnx
dotnet run --project src/DemReview.Desktop -- "путь/к/демке.dem"
```

Пакеты NuGet восстанавливаются в `.nuget/packages` внутри репозитория (см. `nuget.config`).
Тесты на реальных демках берут файлы из `samples/` (в репозиторий не входит); без папки они пропускаются.

Самодостаточные single-file сборки — в `artifacts/<rid>/`:

```bash
./publish.sh             # win-x64 и linux-x64; или: ./publish.sh linux-x64
```
```powershell
.\publish.ps1            # win-x64 и linux-x64; или: .\publish.ps1 win-x64
```

### Структура

| Проект | Назначение |
|---|---|
| `DemReview.Domain` | Неизменяемые модели: матч, раунды, игроки, сэмплы позиций, гранаты, события |
| `DemReview.Application` | Анализ: маршруты, гранаты и их эффективность, раскидки, урон, контекст и экономика, «условия → действия», тепловые карты, фильтры, паттерны, склейка демок в сводный матч, экспорт, локализация |
| `DemReview.Infrastructure` | Парсинг через [DemoFile.Net](https://github.com/saul/demofile-net), данные карт, кеш и библиотека демок в SQLite (EF Core), библиотека раскидок (JSON), настройки, проверка обновлений, платформенные сервисы |
| `DemReview.Desktop` | Avalonia UI (MVVM на CommunityToolkit.Mvvm), радар, DI-хост |
| `DemReview.Tests` | Тесты xUnit v3 |

### Выпуск релиза

1. Обновите `Version` в `Directory.Build.props` и добавьте раздел в [CHANGELOG.md](CHANGELOG.md).
2. Отправьте тег: `git tag v0.2.0 && git push origin v0.2.0`.
3. GitHub Actions прогонит тесты, соберёт архивы для Windows и Linux и создаст **черновик** релиза.
4. Проверьте черновик на странице Releases и опубликуйте его.
